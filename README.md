#  PredTerminal Client

A Java and Spring Boot practice project that consumes the public PredTerminal REST API.

## Technologies

- Java 17
- Spring Boot
- Maven
- REST APIs and HTTP
- JSON / Jackson
- JUnit

## Goals

- Fetch prediction market data from an external API
- Map JSON responses to Java objects
- Practice collections, streams, and exception handling
- Write automated tests
- Learn Git and GitHub workflows
